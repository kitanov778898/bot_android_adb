[ТЕХНИЧЕСКИЙ ПАСПОРТ И ЖЕСТКИЕ ОГРАНИЧЕНИЯ ПРОЕКТА — ИСПОЛЬЗОВАТЬ ПРИ ГЕНЕРАЦИИ КОДА]

1. АППАРАТНОЕ ОКРУЖЕНИЕ:
- Основное устройство: Lenovo TB331FC (Xiaoxin Pad), Android 13, aarch64.
- Вторичное устройство: POCO M6 Pro (1080x2400).
- Ограничения: НЕТ Root-прав.

2. АРХИТЕКТУРА "МАТРЕШКА" (КОНТЕКСТ ВЫПОЛНЕНИЯ):
- Слой 1 (Windows CMD): `C:\...>`. Только для `adb forward tcp:8022 tcp:8022` и `ssh localhost -p 8022`.
- Слой 2 (Termux Bash via SSH): `~/... $`. Управление файлами, Python-скрипты, `dumpsys`, запуск `adb connect` к POCO.
- Слой 3 (Локальный ADB внутри Termux): Скрипт находит порт WLAN отладки (nmap 30000-45000) и делает `adb connect localhost:[порт]`.

3. КРИТИЧЕСКИЕ ОГРАНИЧЕНИЯ ADB (ИЗ РЕПОЗИТОРИЯ):
- ⛔ ЗАПРЕТ: `adb shell input tap/swipe` через WiFi ADB на POCO выдает `java.lang.SecurityException: INJECT_EVENTS permission denied`. Это работает ТОЛЬКО по USB с ПК.
- ✅ РАЗРЕШЕНО: `adb shell getevent` (чтение касаний) работает и по WiFi, и по USB.
- ✅ ЗАПУСК ПРИЛОЖЕНИЙ: Использовать `adb shell am start -f 0x00020000 -n <package>/<activity>` (FLAG_ACTIVITY_REORDER_TO_FRONT), чтобы не перезапускать жизненный цикл игры.
- ✅ СКРИНШОТЫ: Надежный метод: `adb exec-out screencap -p > screen.png`. 
- ⛔ ЛИМИТ ВИДЕО: `adb shell screenrecord` падает с ошибкой encoder failed (err=-38) на 1920x1200. Максимальное рабочее разрешение: 1728x1080.

4. ПРАВИЛА НАПИСАНИЯ PYTHON-КОДА (OPENCV + ADB):
- В модулях/библиотеках (например, `adb_tools.py`) КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать `exit()`. Только `return None` или `return False`. `exit()` допустим только в `main.py` / `bot4.py`.
- Принцип единой ответственности: функция делает ОДНО дело. `find_template` только ищет и возвращает координаты `(cx, cy)` или `None`. Она НЕ делает `tap` и НЕ читает файл с диска.
- Шаблоны (`cv2.imread`) читаются ОДИН РАЗ до начала горячего цикла, а не на каждой итерации.
- Для замеров времени использовать ТОЛЬКО `time.perf_counter()`, а не `time.time()`.
- Функции, принимающие изображения, ждут numpy-массив (BGR), а не путь к файлу (строку).
- Имена переменных и функций: `snake_case`. Константы: `UPPER_CASE`.
- В циклах ожидания (`wait_for_template`) обязательно использовать `timeout` (в секундах) и `interval`, возвращать `None` при неудаче.
</knowledge_base>
