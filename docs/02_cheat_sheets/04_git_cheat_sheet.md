# Личная шпаргалка по Git & Termux

Это краткое справочное руководство по командам, конфигурации и работе с ветками, которые мы подробно разобрали на практике. Оно содержит всё необходимое, чтобы быстро сориентироваться в консоли.

---

## 🛠️ Настройки автоматизации Termux (`~/.bashrc`)

Вы можете добавить эти строки в конфигурационный файл вашего терминала, чтобы работать быстрее и удобнее:

* **Автодополнение по нажатию Tab (для команд Git):**
  ```bash
  pkg install bash-completion
  source ~/.bashrc
  ```
* **Короткое сокращение для очистки экрана (`clr` вместо `clear`):**
  ```bash
  alias clr="clear"
  ```
* **Команда для быстрого исправления опечаток с `ualias`:**
  ```bash
  sed -i 's/ualias/alias/g' ~/.bashrc
  ```
* **Обновление конфигурации в текущей сессии:**
  ```bash
  source ~/.bashrc
  ```

## 🗂️ Справочник основных команд Git

| Команда | Что делает на практике / Контекст применения |
| :--- | :--- |
| **`git status`** | **Главный радар.** Показывает текущее состояние проекта: на какой вы ветке, изменены ли файлы, есть ли неотслеживаемые папки. |
| **`git config --global core.quotepath false`** | **Исправление кодировки.** Включает корректное отображение русских букв в названиях файлов вместо цифровых кодов вроде `\320\267...`. |
| **`git diff`** | **Просмотр изменений.** Показывает точные построчные правки в файлах. Зеленый цвет с плюсом `+` — добавленные строки, красный с минусом `-` — удаленные. *Для выхода нажмите английскую клавишу `Q`.* |
| **`git diff "имя_файла.txt"`** | **Точечный просмотр.** Показывает изменения только для одного конкретного файла. Кавычки обязательны, если в имени есть пробелы. |
| **`git restore "имя_файла.txt"`** | **Сброс и отмена.** Полностью отменяет все незакоммиченные правки в файле, возвращая его к состоянию чистого оригинала. |
| **`git branch`** | **Список веток.** Выводит список всех созданных веток проекта. Символ `*` подсвечивает ветку, в которой вы находитесь прямо сейчас. |
| **`git checkout -b имя_ветки`** | **Создание черновика.** Создает новую локальную ветку на телефоне и сразу переключает вас внутрь неё. Сервер об этой ветке пока не знает. |
| **`git switch имя_ветки`** | **Прыжок между ветками.** Позволяет мгновенно переключаться между существующими ветками (например, `git switch main` или `git switch cleanup`). |
| **`git mv "файл.txt" папка/`** | **Умный перенос.** Перемещает файл в другую папку силами Git. Файл сразу остается на контроле у системы и подсвечивается зеленым как `renamed`. |
| **`git commit -m "Сообщение"`** | **Точка восстановления.** Навсегда записывает подготовленные (зеленые) изменения в историю репозитория на устройстве и снабжает их вашим комментарием. |
| **`git push -u origin имя_ветки`** | **Первая выгрузка.** Отправляет новую локальную ветку на GitHub в первый раз и накрепко связывает её с телефоном для последующих обновлений. |
| **`git push`** | **Синхронизация.** Быстро загружает все сделанные вами новые коммиты текущей ветки на удаленный сервер GitHub. |
| **`git merge имя_ветки`** | **Слияние результатов.** Команда вливает изменения из указанной ветки в ту, на которой вы стоите сейчас (например, переносит наведенный порядок в `main`). |

## 💡 Полезные напоминания:
1. **Точка входа неизменна:** При переключении веток путь к проекту (`~/.../downloads/bot_android_adb`) не меняется. Git просто переставляет файлы в одной папке как декорации на сцене.
2. **Внимательность к деталям:** Любой лишний перенос строки, пробел или пустая строка — это изменение для Git. Всегда проверяйте себя через `git diff`, чтобы не плодить пустые коммиты.
