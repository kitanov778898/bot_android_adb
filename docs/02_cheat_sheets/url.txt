1. Выключить дисплей (Принудительный сон)

	adb shell input keyevent KEYCODE_SLEEP

2. Включить дисплей (Пробуждение)

adb shell input keyevent KEYCODE_WAKEUP

3. текущий статус экрана
—————- windows ———————-
	adb shell dumpsys display | findstr mScreenState

—————- Linux ———————-
	adb shell dumpsys display | grep mScreenState

пример вывода

~/.../bot_android_adb/new $ adb shell dumpsys display | grep mScreenState
  mScreenState=ON

# 1. Запрашиваем инфо об экране
# 2. Находим строчку с mScreenState
# 3. Режем её по знаку "=" и забираем правую часть
adb shell dumpsys display | grep mScreenState | cut -d '=' -f 2

# В консоли твоего бота теперь появится только чистое слово:
# ON
