# 🤖 ИИ-ассистент: Руководство по использованию промпта

Этот документ описывает, как правильно настроить и использовать системный промпт для ИИ-ассистента в рамках проекта.

## 1. Где находится промпт
Основной файл системных инструкций находится здесь:
`docs/01_project_handoff/ai_system_prompt.md`

## 2. Как применить промпт в новом чате
1. Открой настройки ИИ-чата (Custom Instructions / System Prompt).
2. Скопируй **всё содержимое** файла `ai_system_prompt.md`.
3. Вставь его в поле системных инструкций и сохрани.

## 3. Что дает этот промпт
- **Контекст**: ИИ знает, что ты работаешь в связке Windows CMD -> ADB -> Termux -> POCO (WiFi).
- **Ограничения**: ИИ не будет предлагать `adb shell input tap` по WiFi (знает про `INJECT_EVENTS`), не предложит `exit()` внутри модулей и учтет лимиты `screenrecord`.
- **Формат**: ИИ будет выдавать ответы пошагово, ожидая твоего подтверждения ("1" или "готово") перед следующим шагом.

## 4. Примеры эффективных запросов к ИИ
- *"Шаг 1: Напиши команду для захвата экрана в raw-формате через exec-out и сохранения его в numpy-массив в Python."*
- *"У меня ошибка 'encoder failed err=-38' при записи видео. Напомни ограничение и дай рабочую команду."*
- *"Напиши функцию `wait_for_template`, которая принимает numpy-массив экрана и путь к шаблону, с таймаутом и интервалом."*

## 5. Обновление промпта
Если в проекте появились новые жесткие ограничения или правила, обнови файл `ai_system_prompt.md`, закоммить изменения и скопируй новый текст в настройки ИИ.
