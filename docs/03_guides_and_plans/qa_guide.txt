КОМАНДА qa - РУКОВОДСТВО


ЧТО ДЕЛАЕТ qa

Функция qa (quick analyze) - это инструмент для быстрого запуска Python-скриптов с автоматическим сохранением результата в буфер обмена.

Синтаксис:
    qa <имя_файла.py>

Что происходит при вызове:
1. Показывает содержимое файла с номерами строк
2. Запускает Python-скрипт
3. Сохраняет всё (код + вывод + ошибки) во временный файл
4. Копирует результат в буфер обмена Android

Пример:
    qa test.py

После выполнения можешь вставить результат в любое приложение (заметки, чат, документ).


КАК РАБОТАЕТ && vs ;


Оператор && (И)

Выполняет следующую команду ТОЛЬКО ЕСЛИ предыдущая завершилась успешно (код возврата 0).

Пример:
    command1 && command2

- Если command1 успешна -> выполнится command2
- Если command1 упала -> command2 НЕ выполнится

Когда использовать:
Когда нужна строгая последовательность: "если А сработало, тогда делай Б".


Оператор ; (последовательность)

Выполняет следующую команду ВСЕГДА, независимо от результата предыдущей.

Пример:
    command1 ; command2

- command1 выполнится
- command2 выполнится ВСЕГДА, даже если command1 упала

Когда использовать:
Когда нужно выполнить команды подряд, но результат одной не должен блокировать другую.


Сравнение

Сценарий                      &&                    ;
Первая команда успешна       Вторая выполнится     Вторая выполнится
Первая команда упала         Вторая НЕ выполнится  Вторая выполнится

В функции qa:
    { cat -n "$1" && python "$1"; } > $TMPDIR/out.txt 2>&1 ; cat -n $TMPDIR/out.txt | termux-clipboard-set

- Внутри { }: cat и python связаны через && (если файл не найден, Python не запустится)
- После { }: используется ; (в буфер попадет всё, даже если Python упал)


ЧТО ТАКОЕ $1 В ФУНКЦИИ

$1 - это ПЕРВЫЙ АРГУМЕНТ, переданный функции при вызове.

Пример:
    qa() {
        echo "Файл: $1"
        python "$1"
    }

Вызов:
    qa test.py

Что происходит:
- $1 заменяется на test.py
- Функция выполняет: echo "Файл: test.py" и python "test.py"

Другие аргументы:
- $1 - первый аргумент
- $2 - второй аргумент
- $3 - третий аргумент
- $@ - все аргументы сразу

Пример с несколькими аргументами:
    myfunc() {
        echo "Первый: $1"
        echo "Второй: $2"
        echo "Все: $@"
    }
    
    myfunc apple banana cherry

Вывод:
    Первый: apple
    Второй: banana
    Все: apple banana cherry


ПОЛНЫЙ КОД ФУНКЦИИ qa

    qa() {
        { cat -n "$1" && python "$1"; } > $TMPDIR/out.txt 2>&1 ; cat -n $TMPDIR/out.txt | termux-clipboard-set
    }

Разбор по частям:

1. { cat -n "$1" && python "$1"; } - группа команд:
   - cat -n "$1" - показывает файл с номерами строк
   - && - если cat успешен, запускаем python "$1"
   - ; перед } - обязательно в bash

2. > $TMPDIR/out.txt 2>&1 - перенаправление:
   - > - stdout (нормальный вывод) в файл
   - 2>&1 - stderr (ошибки) туда же, куда stdout
   - Результат: всё (код + вывод + ошибки) в одном файле

3. ; - всегда выполняем следующую команду

4. cat -n $TMPDIR/out.txt | termux-clipboard-set - отправка в буфер:
   - cat -n - читает файл с номерами строк
   - | - pipe, передает вывод в следующую команду
   - termux-clipboard-set - кладет текст в буфер обмена Android


УСТАНОВКА

Добавь в ~/.bashrc:

    qa() {
        { cat -n "$1" && python "$1"; } > $TMPDIR/out.txt 2>&1 ; cat -n $TMPDIR/out.txt | termux-clipboard-set
    }

Перезагрузи:
    source ~/.bashrc

Используй:
    qa test.py
