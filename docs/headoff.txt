1. ЦЕЛЬ ПРОЕКТА
----------------------------------------------------------------
Написать бота, который смотрит на экран Android-устройства,
находит кнопки по PNG-шаблонам (OpenCV matchTemplate) и
тапает по ним через adb. В перспективе — не «спать и кликать»,
а реагировать на состояние экрана (машина состояний).

Игра-пример: Fast Car / Hill Climb.
Окружение: планшет в Termux, ADB подключается к устройству.

6. КЛЮЧЕВЫЕ НАХОДКИ (не забыть!)
----------------------------------------------------------------
--- Лимит кодека screenrecord ---
1920x1200 НЕ тянет — Encoder failed (err=-38).
Рабочий максимум: 1920x1080 (обрезает до 1728x1080, offset x=96).
Безопасные: 1728x1080, 1600x1000, 1280x720.
Высота > 1080 — кодек отваливается.

--- Скриншот — узкое место ---
adb shell screencap -p = 400–600 мс на цикл (медленно).
Причина: PNG-сжатие + двойная передача через shell.
Решение: adb exec-out screencap БЕЗ -p (raw) + декод в памяти.
Ожидаемое ускорение: 5–10 раз.

--- matchTemplate — суть ---
    result = cv2.matchTemplate(screen, template, cv2.TM_CCOEFF_NORMED)
    _, max_val, _, max_loc = cv2.minMaxLoc(result)
max_val — уверенность (0..1), чем больше — тем лучше.
max_loc — координаты ВЕРХНЕГО ЛЕВОГО угла найденного фрагмента.
Центр = (max_loc[0] + w//2, max_loc[1] + h//2).
Порог: обычно 0.85–0.95. TM_CCOEFF_NORMED — стандарт для игр и UI,
устойчив к изменению яркости, значения от -1 до 1.

--- BGR, а не RGB ---
OpenCV использует порядок Blue, Green, Red:
    Красный = (0, 0, 255)
    Зелёный = (0, 255, 0)

2. Шаблон больше экрана → ошибка. Проверять через assert.

----------------------------------------------------------------
10. ПРАВИЛА, КОТОРЫЕ МЫ ВЫВЕЛИ ПО ХОДУ
----------------------------------------------------------------
- В модуле (библиотеке) НЕ вызывать exit(). Только return.
- exit(1) — для ошибки, exit(0) — успех. Только в main.py.
- Функция делает ОДНО дело. Не «искать + тапать + выходить».
- Имена: snake_case. Функции — глагол в начале (find_, tap_, grab_).
- Параметры функции — маленькими буквами. Константы — БОЛЬШИМИ.
- Если функция может не найти — вернуть None, а не падать.
- В любом цикле ожидания: timeout + interval + return None.
- Если что-то читаем с диска — проверяем на None сразу.
- Докстринг — первая строка в функции, в тройных кавычках.
  Формат: краткое описание + Args/Параметры + Returns.

11. ПСИХОЛОГИЧЕСКИЙ КОНТЕКСТ (важно!)
----------------------------------------------------------------
Это не «мотивашка». Это решения, принятые в ясном уме.
Через полгода они не восстановятся задним числом.

- Не гнаться за «пятиклассником» — это тревожная мысль,
  а не реальность. По коду видно уверенное владение
  subprocess, cv2, numpy, дефолтами, while True.
- Прогресс есть: кодек, OpenCV, matchTemplate — большой путь.
  Ощущение прогресса обманчиво, список пройденного — нет.
- Мозг достраивает понимание во сне и на паузах.
  Застрять и ничего не делать — тоже полезно.
- Работать маленькими шагами, по одной функции за раз.
  Соблазн «переписать всё сразу» убивает проекты чаще,
  чем ошибки в коде.
- Интерес важнее скорости.
