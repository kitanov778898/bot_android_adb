📅 ДЕНЬ 1. Установка Termux и первый запуск Python
═══════════════════════════════════════════════════════════════════════════════

ЦЕЛЬ ДНЯ: Python работает на телефоне, ты можешь запустить скрипт.

    [ ] 1. Скачать Termux из F-Droid (НЕ из Google Play — там старая версия)
    [ ] 2. Открыть Termux, выполнить: pkg update && pkg upgrade
    [ ] 3. Установить Python: pkg install python
    [ ] 4. Проверить: python --version (должно показать версию)
    [ ] 5. Создать файл: nano test.py
    [ ] 6. Написать внутри: print("Привет, POCO!")
    [ ] 7. Запустить: python test.py
    [ ] 8. Выйти из nano: Ctrl+X

📅 ДЕНЬ 3. Первый реальный клик
═══════════════════════════════════════════════════════════════════════════════

ЦЕЛЬ ДНЯ: Телефон кликает сам по заданным координатам.

    [ ] 1. Включить в настройках разработчика: "Показывать нажатия"
           (видеть, сработал ли клик)
    [ ] 2. Включить "Определение местоположения указателя" (Pointer location)
           — показывает X,Y в шторке уведомлений
    [ ] 3. Найти координаты нужной кнопки (записать: X=_____, Y=_____)
    [ ] 4. В Termux выполнить вручную: input tap X Y
    [ ] 5. Увидеть кружок нажатия в этом месте = успех
    [ ] 6. В clicker.py заменить print на os.system("input tap X Y")
    [ ] 7. Запустить — телефон кликает сам!
