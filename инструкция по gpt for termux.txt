================================================================
 ИНСТРУКЦИЯ: ЗАПУСК НЕЙРОСЕТИ В TERMUX (ANDROID) ЧЕРЕЗ CLI
================================================================

Эта инструкция поможет настроить консольный ИИ-инструмент "tgpt".
Он работает через интернет, использует бесплатные шлюзы к LLM-моделям
(GPT, Llama, Gemini) и автоматически переключает их, если какая-то
сеть перестает отвечать.

----------------------------------------------------------------
 ШАГ 1: ОБНОВЛЕНИЕ ОКРУЖЕНИЯ И УСТАНОВКА ЗАВИСИМОСТЕЙ
----------------------------------------------------------------
Открой Termux и введи команду для обновления системных пакетов:

    pkg update && pkg upgrade -y

Установи необходимые утилиты (скачиватель curl, текстовый редактор micro):

    pkg install curl micro -y

----------------------------------------------------------------
 ШАГ 2: УСТАНОВКА КОНСОЛЬНОГО ИИ-КЛИЕНТА (TGPT)
----------------------------------------------------------------
Скачай и автоматически установи официальный скрипт tgpt:

    curl -sSL https://githubusercontent.com | bash

После завершения установки утилита будет готова к работе.

----------------------------------------------------------------
 ШАГ 3: КАК ПОЛЬЗОВАТЬСЯ НЕЙРОСЕТЬЮ В ТЕРМИНАЛЕ
----------------------------------------------------------------

1. Одиночный быстрый запрос (ответ выведется и программа закроется):
   👉 tgpt "Напиши простой скрипт на Python для вычисления процентов"

2. Интерактивный режим чата (ИИ запоминает контекст беседы):
   👉 tgpt -i
   (Чтобы выйти из режима чата, введи: exit)

3. Генерация кода и сохранение его прямо в файл:
   👉 tgpt "Напиши код игры змейка на python" > snake.py

----------------------------------------------------------------
 ШАГ 4: КАК СМОТРЕТЬ И РЕДАКТИРОВАТЬ ЭТОТ ФАЙЛ
----------------------------------------------------------------
• Чтобы открыть этот файл и почитать его внутри Termux:
    micro ai_instruction.txt
    (Для выхода из редактора micro нажми Ctrl+Q)

• Если ты захочешь скинуть инструкцию в память телефона (в загрузки):
    termux-setup-storage
    (разреши доступ к памяти в появившемся окне)
    cp ai_instruction.txt /sdcard/Download/
