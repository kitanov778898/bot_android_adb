======================================================================
 ПОЛНОЕ АВТОНОМНОЕ РУКОВОДСТВО ПО GIT: ANDROID (TERMUX) И WINDOWS (CMD)
======================================================================
Этот документ содержит исчерпывающие инструкции для управления кодом
внутри локального репозитория и синхронизации через облако GitHub.

----------------------------------------------------------------------
БЛОК 1: ПЕРВИЧНАЯ ПРОВЕРКА И НАСТРОЙКА ПРОФИЛЯ АВТОРА
----------------------------------------------------------------------
Перед началом работы убедитесь, что Git установлен, и система знает, 
кто подписывает сохранения (коммиты).

1. Проверить, установлен ли Git и узнать его точную версию:
   git --version

2. Посмотреть все текущие настройки профиля:
   git config --list

3. Установить или обновить имя автора и email (если список пуст):
   git config --global user.name "Seal100_tablet"
   git config --global user.email "seal100@yandex.ru"

----------------------------------------------------------------------
БЛОК 2: ИНИЦИАЛИЗАЦИЯ И РЕШЕНИЕ ПРОБЛЕМЫ ДОСТУПА В ANDROID (TERMUX)
----------------------------------------------------------------------
1. Чтобы связать Termux с общей памятью планшета (папкой Download), 
   введите команду и нажмите "Разрешить" на экране:
   termux-setup-storage

2. Перейдите в рабочую папку (например, с ботом):
   cd /storage/emulated/0/Download/bot_android_adb

3. Создать новый локальный репозиторий Git в текущей папке:
   git init
   (Команда создаст скрытую папку .git — «мозг» репозитория).

4. РЕШЕНИЕ ОШИБКИ ПОД Android (fatal: detected dubious ownership):
   Если при вводе команд Git блокирует работу из-за разницы прав в Android,
   внесите папку в список доверенных безопасных директорий:
   git config --global --add safe.directory /storage/emulated/0/Download/bot_android_adb

----------------------------------------------------------------------
БЛОК 3: ИСКЛЮЧЕНИЕ МУСОРА ИЗ ОТСЛЕЖИВАНИЯ (.gitignore)
----------------------------------------------------------------------
Файлы кэша Python (*.pyc, __pycache__/) нужно скрывать от Git.
Для этого создается файл с именем .gitignore.

Пример правильного содержимого .gitignore (скриншоты бота остаются!):
   __pycache__/
   *.pyc

Посмотреть, какие файлы сейчас видит Git (измененные или неотслеживаемые):
   git status

----------------------------------------------------------------------
БЛОК 4: ЕЖЕДНЕВНЫЙ ЦИКЛ НА ЛЮБОМ УСТРОЙСТВЕ (СОХРАНЕНИЕ И ОТПРАВКА)
----------------------------------------------------------------------
Когда вы дописали код или добавили файлы, выполните 4 шага:

1. Проверить статус изменений:
   git status

2. Добавить все файлы (или конкретный файл) в индекс для сохранения:
   git add .                     (добавить всё, точка обязательна)
   git add имя_файла.txt         (добавить только один файл)

3. Зафиксировать изменения локально с текстовым комментарием:
   git commit -m "Ваше описание изменений на русском или английском"

4. Отправить созданные сохранения на сервер GitHub в ветку main:
   git push origin main
   (или просто: git push)

----------------------------------------------------------------------
БЛОК 5: СИНХРОНИЗАЦИЯ: КАК ОБНОВИТЬ КОД НА ВТОРОМ УСТРОЙСТВЕ
----------------------------------------------------------------------
Если вы поработали на планшете и сделали 'git push', то чтобы 
забрать актуальный код на компьютере (или наоборот):

1. Перейдите в папку проекта на устройстве, которое хотите обновить:
   cd путь/к/папке/проекта

2. Скачайте последние обновления из облака одной командой:
   git pull

*Правило:* Всегда делайте 'git pull' перед тем, как начать писать код!

----------------------------------------------------------------------
БЛОК 6: ПЕРВЫЙ ЗАПУСК ПРОЕКТА НА НОВОМ УСТРОЙСТВЕ (КЛОНИРОВАНИЕ)
----------------------------------------------------------------------
Если на компьютере или новом телефоне проекта еще нет, скачайте его.

Скачивание по безопасному протоколу SSH (если перенесен ключ id_ed25519):
   git clone git@github.com:kitanov778898/bot_android_adb.git

Проверить, работает ли SSH-связь устройства с сервером GitHub:
   ssh -T git@github.com

Скачивание по протоколу HTTPS (если нужно авторизоваться через браузер):
   git clone https://github.com

----------------------------------------------------------------------
БЛОК 7: ПОЛЕЗНЫЕ СЛУЖЕБНЫЕ КОМАНДЫ ДЛЯ АВТОНОМНОЙ РАБОТЫ
----------------------------------------------------------------------
* Посмотреть историю всех прошлых сохранений (коммитов) одной строкой:
  git log --oneline

* Посмотреть, какие конкретно строчки кода были изменены прямо сейчас 
  (до того, как вы сделали коммит):
  git diff

* Сбросить все незакоммиченные изменения и вернуть файлы 
  к состоянию последнего сохранения (Внимание: изменения сотрутся!):
  git checkout .
